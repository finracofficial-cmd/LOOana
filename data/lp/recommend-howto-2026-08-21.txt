================================================================
関連セクションの具体的ないじり方（手順書）
2026-08-21 作成
================================================================

テーマの実体を公開HTMLから特定しました。**Dawn系**です。

  セクションID   template--22315360289010__related-products
  ファイル       sections/related-products.liquid
  カスタム要素   <product-recommendations data-url="/recommendations/products?limit=10">
  見出し         「よく一緒に購入されている商品」
  カード         snippets/card-product.liquid（`card__heading` が1カードにつき2か所）
  枠数           10（grid__item が10個）
  CSS            assets/section-related-products.css

★ セクションのHTMLは**外から直接叩いて確認できます**。編集の前後で必ずこれを見比べてください。

  curl -s "https://looty-japan.com/recommendations/products?section_id=template--22315360289010__related-products&product_id=9056544817394&limit=10&v=$RANDOM" \
    | grep -c 'grid__item'

  ⚠️ `.json` を付けたエンドポイント（`/recommendations/products.json?...`）は
    **テーマを通らない**ので、Liquidを編集しても結果が変わりません。
    確認は必ず `section_id=` を付けた**HTMLを返すほう**で行うこと。


----------------------------------------------------------------
0. 最初にやること（毎回）
----------------------------------------------------------------

  管理画面 → オンラインストア → テーマ → 現在のテーマの「…」→ **複製**

  名前は「バックアップ 2026-08-21」など。壊れたら公開テーマを差し戻すだけで戻せます。
  **コードを1文字でも触る前に必ず。**


----------------------------------------------------------------
1. コードを触らずにできること（テーマエディタだけ）
----------------------------------------------------------------

  管理画面 → オンラインストア → テーマ → カスタマイズ →
  上部のドロップダウンで「商品」テンプレートを選ぶ → 左の
  「関連商品 / Related products」セクションをクリック

  ここで変えられるもの:
    ・見出し（いまは「よく一緒に購入されている商品」）
    ・**表示する商品数**
    ・列数・カラースキーム・余白

  ⚠️ **ただし「表示する商品数」を10から減らさないでください。**
    この設定はそのまま `limit=` に入るので、10→6にすると
    **Shopifyから6件しか取ってこなくなります。**
    このあと季節で間引くので、手元に10件無いと枠が埋まりません。
    **10のまま固定。減らすのはLiquid側でやります。**


----------------------------------------------------------------
2. 編集① タイトルの接頭辞を落とす（先にこれだけやるのを勧めます）
----------------------------------------------------------------

  ■ 場所
    テーマ → 「…」→ **コードを編集** → 検索窓に `card-product` →
    **snippets/card-product.liquid**

  ■ 探す文字列（`Ctrl+F` / `Cmd+F`）

      card_product.title

    Dawnではタイトルの出力が **2か所** あります（`card__heading` が1カードに2つ出ているのが
    その証拠）。**両方直してください。**片方だけだと表示条件によって直らない場合があります。

  ■ 直し方（before → after）

    before:
      {{ card_product.title | escape }}

    after:
      {{ card_product.title
         | remove: '【本日終了⏰】'
         | remove: '【累計15万台突破🏆】'
         | remove: '【顧客満足度No.1獲得商品🥇】'
         | remove: '【顧客満足度No.1獲得】'
         | remove: '【全国送料無料🚗】'
         | strip
         | escape }}

    ⚠️ `| escape` は**最後に置く**こと。先に escape すると【】が文字実体に変わって
      remove が効かなくなります。
    ⚠️ 絵文字を含む文字列なので、**コピペで入れてください。**手打ちだと
      ⏰🏆🥇🚗 が別のコードポイントになって一致しないことがあります。

  ■ 影響範囲（正直に）
    `card-product.liquid` は**商品グリッド全部で共通**です。関連セクションだけでなく
    コレクションページ・検索結果・TOPのおすすめにも効きます。
    **商品ページのH1（大きいタイトル）は別ファイル（sections/main-product.liquid）なので
    変わりません。広告・SEO・商品名そのものにも影響しません。**

    → 全グリッドで直るのは、たぶん望ましい方向です。ただし
      「関連セクションだけで効果を測りたい」なら、card-product.liquid を
      `card-product-clean.liquid` という名前でコピーして、
      related-products.liquid の `{% render 'card-product' %}` だけを
      `{% render 'card-product-clean' %}` に差し替えてください。

  ■ 確認
    curl -s "https://looty-japan.com/recommendations/products?section_id=template--22315360289010__related-products&product_id=9056544817394&limit=10&v=$RANDOM" | grep -o 'LOOTY[^<]\{0,30\}' | head

    「【本日終了⏰】」が消えて「LOOTY ムダ毛シェーバー」から始まっていれば成功。

3. 編集② 季節で間引く
----------------------------------------------------------------

  ■ 前提
    `data/tags/season-tags-2026-08-20.txt` の季節タグを先に付けておくのが本筋です。
    ただし**下のコードは「季節タグを1つも持たない商品は通す」設計（fail-open）**
    にしてあるので、**タグが未適用でも枠が空にはなりません。**
    順番はどちらが先でも壊れません。

  ■ 場所
    コードを編集 → **sections/related-products.liquid**

  ■ 探す文字列

      for recommendation in recommendations.products

  ■ ループの「直前」に貼るもの

    {%- comment -%} 月から季節を決める。夏は自店の実測に合わせて9月まで {%- endcomment -%}
    {%- assign m = 'now' | date: '%-m' | plus: 0 -%}
    {%- if m >= 3 and m <= 5 -%}
      {%- assign season = '季節:春' -%}
    {%- elsif m >= 6 and m <= 9 -%}
      {%- assign season = '季節:夏' -%}
    {%- elsif m >= 10 and m <= 11 -%}
      {%- assign season = '季節:秋' -%}
    {%- else -%}
      {%- assign season = '季節:冬' -%}
    {%- endif -%}
    {%- assign shown = 0 -%}

  ■ ループの中身を囲う

    before:
      {%- for recommendation in recommendations.products -%}
        <li class="grid__item">
          {% render 'card-product', card_product: recommendation, ... %}
        </li>
      {%- endfor -%}

    after:
      {%- for recommendation in recommendations.products -%}
        {%- if shown >= 6 -%}{%- break -%}{%- endif -%}

        {%- assign pass = false -%}
        {%- assign tagstr = recommendation.tags | join: ',' -%}
        {%- unless tagstr contains '季節:' -%}
          {%- comment -%} 季節タグ未設定の商品は通す（付け忘れで消えないように） {%- endcomment -%}
          {%- assign pass = true -%}
        {%- endunless -%}
        {%- if recommendation.tags contains season or recommendation.tags contains '季節:通年' -%}
          {%- assign pass = true -%}
        {%- endif -%}
        {%- unless recommendation.available -%}
          {%- assign pass = false -%}
        {%- endunless -%}

        {%- if pass -%}
          {%- assign shown = shown | plus: 1 -%}
          <li class="grid__item">
            {% render 'card-product', card_product: recommendation, ... %}
          </li>
        {%- endif -%}
      {%- endfor -%}

    ※ `{% render 'card-product', ... %}` の行は**いま書かれているものをそのまま使う**こと。
      引数（`show_secondary_image` など）はテーマによって違うので、消さずに囲うだけにします。

  ■ ★ここが効く理由（設定値として一番大事な行）

      {%- elsif m >= 6 and m <= 9 -%}  {%- assign season = '季節:夏' -%}

    暦の夏（6〜8月）より1か月長くしています。自店は9月末まで冷感・UVが売れているため。
    **これにより10月1日に、夏商品が関連枠から自動で消えます。**
    Shopifyの `related` は履歴ベースなので放っておくと数週間〜数ヶ月遅れて追随します。
    その遅れを丸ごと飛ばせるのがこの3行の価値です。

  ■ 確認

    curl -s "https://looty-japan.com/recommendations/products?section_id=template--22315360289010__related-products&product_id=9030597509362&limit=10&v=$RANDOM" | grep -c 'grid__item'

    形状記憶日傘（9030597509362）は春夏が8/10なので、
    **タグ適用後・10月以降**なら枠が大きく減るはずです。
    いまは8月（＝夏）なので**減らないのが正常**です。減っていたらタグの付け方を疑ってください。

  ■ 枠数について
    `shown >= 6` で6枠に絞っています。10枠から減らす理由は
    「スマホで10枚並ぶと選べない」ですが、これは**実測のない判断**です。
    6が不安なら8にしてください。**この数字だけは後から自由に変えられます。**


----------------------------------------------------------------
4. 編集③ 補充枠（あとまわしでいい）
----------------------------------------------------------------

  季節で間引いたあと6枠に足りないときの補充と、
  「稼働中の新商品」「非広告の在庫商品」を差し込む枠です。

  ■ 準備: 手動コレクションを1つ作る
    管理画面 → コレクション → コレクションを作成 → **手動**
    タイトル「関連枠の補充」／ハンドルを **recommend-fill** にする
    （ハンドルはコレクション編集画面の下の「検索エンジン用の表示」で確認・変更）

    中身は上から順に入れる（並び順が優先度になります）:
      1. 3D足臭リセットブラシ    ← 履歴ゼロで関連枠に1度も出ていない
      2. 快適マジックインソール
      3. 完全遮光・接触冷感UVハット
      4. W固定スマホ車載ホルダー
      5. 接触冷感UVアームカバー
      6. 携帯電動シェーバー      ← ここから下は非広告（広告費ゼロで売れる枠）
      7. 癒しの指圧マット
      8. スタイルアップインナー
      9. ナノバブルシャワーヘッド
     10. 高吸水・速乾ヘアドライタオル

    ⚠️ このコレクションは**どこにも公開しない**（オンラインストアの公開先から外す）。
      関連枠から読むためだけのものです。

  ■ コード: 編集②の `{%- endfor -%}` の直後に足す

    {%- assign fill = collections['recommend-fill'].products -%}
    {%- for p in fill -%}
      {%- if shown >= 6 -%}{%- break -%}{%- endif -%}
      {%- if p.available and p.id != product.id
             and (p.tags contains season or p.tags contains '季節:通年') -%}
        {%- assign shown = shown | plus: 1 -%}
        <li class="grid__item">
          {% render 'card-product', card_product: p, ... %}
        </li>
      {%- endif -%}
    {%- endfor -%}

    ⚠️ すでに上のループで出た商品が重複する可能性があります。
      気になるなら、出した商品のIDを文字列に貯めて `contains` で弾いてください。
      ただし**まずは重複したままで構いません。**実際に重複するか見てからで十分です。


----------------------------------------------------------------
5. やる順番
----------------------------------------------------------------

  1. テーマを複製してバックアップ                          （2分）
  2. **編集①（タイトル接頭辞）だけ入れて7日置く**          （10分）
       → 異商品ミックス率（Σ商品別orders − 全店orders）で判定
  3. 季節タグ42商品を適用                                （15分・管理画面で5回の一括操作）
  4. 編集②（季節フィルタ）                               （20分）
  5. カテゴリタグ9グループ ＋ 編集③（補充枠）             （あとまわし）

  ★ 2 と 4 を同時に入れないでください。**どちらが効いたか分からなくなります。**
    関連枠まわりで測れる指標は異商品ミックス率ひとつしかないので、
    1つずつしか切り分けられません。

  ★ 3〜4 は **9月中に終わらせる**。10月1日に効き始めるものなので、
    9月末を過ぎると1シーズンぶん取り逃がします。


----------------------------------------------------------------
6. 壊れたときの戻し方
----------------------------------------------------------------

  ・関連セクションが**真っ白になった** → Liquidの `{%- endif -%}` / `{%- endfor -%}` の
    対応が崩れています。コードエディタが赤線を出すので、そこを見る
  ・**枠が0件になった** → 季節タグの表記ゆれ。`季節:夏` の**コロンが半角**か確認。
    全角「：」だと一致しません
  ・**何が起きたか分からない** → テーマ → バックアップ側の「…」→ 公開する。即戻ります

  ⚠️ 公開テーマを直接編集しているので、編集中の状態がそのままお客さんに見えます。
    不安なら**バックアップのほうを公開して、元テーマ（非公開）で編集 → 終わったら公開を戻す**
    のが安全です。
