LOOTY VIP特典「2個以上」への変更手順　2026-10-09作成（夕方に実施予定）
※ 設定はユーザーが実行。こちらからは書き込みしない。

────────────────────────────────
考え方
────────────────────────────────
・VIP特典の条件は「商品2個以上」（優先配送・VIP特典の行は数えない）
・注文確認メールは個数だけで判定する（金額は見ない）
・Monster Cart（カートの無料ギフト）は、個数の条件が選べれば「2個」にそろえる
　選べなければ「7,000円以上」で代用する。主力はほぼ全部3,980円なので、2個買えば必ず7,000円を超える
　　同じ商品2個（10%引き後）＝7,164円／違う商品2個＝7,960円

────────────────────────────────
手順1　Monster Cart：無料ギフトの条件を「2個」（または7,000円）に
────────────────────────────────
1. Shopify管理画面 → アプリ → Monster Cart Upsell+Free Gifts
2. Upsell Campaigns →（VIP特典の）Add To Unlock を開く
3. 条件を変える
　・条件の種類に「個数（Item count / Quantity）」が選べる場合 → 個数「2」にする（メールと完全にそろう）
　・「金額」しか選べない場合 → 8,000 → 7,000 にする
　　（7,000円だと1個8,980円のネックマッサージャーは優先配送が無料になるが、メールのクーポンは出ない。人数はごくわずか）
4. バーの文言（未達のとき）を変更
　　変更前：あと{残り金額}でVIP特典｜優先発送が無料＋次回使える1,000円OFFクーポン
　　変更後：2個以上でVIP特典｜優先発送が無料＋次回使える1,000円OFFクーポン
　　（金額の条件にした場合は：あと{残り金額}でVIP特典（2個でOK）｜…）
　　（{残り金額} はアプリの差し込みをそのまま使う）
5. 達成時の文言は今のままでOK
6. 保存

────────────────────────────────
手順2　注文確認メール：クーポン案内を「2個以上」で出す（個数だけで判定・優先配送は数えない）
────────────────────────────────
1. Shopify管理画面 → 設定 → 通知 → お客様通知 →「注文の確認」→「コードを編集」
2. 10/3に貼った「{% if subtotal_price >= 800000 %}」から「{% endif %}」までのブロックを探す
3. そのブロックを丸ごと、下に置き換える（「▼ここから」「▲ここまで」の行は貼らない）

▼ここから
{% assign looty_vip_qty = 0 %}
{% for line in subtotal_line_items %}
  {% unless line.product.title contains '優先配送' or line.product.title contains 'VIP' %}
    {% assign looty_vip_qty = looty_vip_qty | plus: line.quantity %}
  {% endunless %}
{% endfor %}
{% if looty_vip_qty >= 2 %}
<p><strong>LOOTY VIP特典のご案内</strong><br>
VIP特典の対象となるお買い上げ、誠にありがとうございます。<br>
今回のご注文は優先発送（通常より早く処理・発送）でご用意いたします。<br><br>
次回のお買い物で使える1,000円OFFクーポンをお送りします。<br>
クーポンコード：VIP1000<br>
ご利用条件：5,000円以上のご注文・お一人さま1回まで<br>
有効期限：11月30日まで</p>
{% endif %}
▲ここまで

　このコードがしていること
　・注文の商品を1行ずつ見て、「優先配送」「VIP特典」の行は数えない
　・残りの商品の「個数」を合計する（金額は見ない）
　・2個以上なら、クーポン案内を出す
　　（例）ナノ2個 → 出る／ナノ1個＋クリーナー1個 → 出る
　　　　　ネックマッサージャー1個（8,980円） → 出ない（1個なので）
　　　　　ナノ1個＋有料の優先配送 → 出ない（優先配送は数えない）

4. 表示の確認（プレビュー）
　・プレビューの見本注文は1点なので、そのままだと案内は出ないのが正常
　・出るか確かめたいときだけ、一時的に「looty_vip_qty >= 2」を「looty_vip_qty >= 0」に変えて「プレビュー」
　　→ 案内が出ることを確認 → 必ず「looty_vip_qty >= 2」に戻す
5. 保存
6. 確認はプレビュー（手順4）で十分。実際のメールで見たい場合だけ、自分のメールアドレスで2個のテスト注文をして、すぐキャンセル・返金する（決済手数料が少しかかる場合あり）

────────────────────────────────
手順3　VIP1000クーポン：変更なし
────────────────────────────────
・最低購入金額5,000円・1人1回・11/30まで のまま

────────────────────────────────
テスト（スマホのシークレットウィンドウで）
────────────────────────────────
□ ナノガラスを「2個」でカートへ（7,164円）→ 優先配送が0円で自動で入る
□ 1個に減らす（3,980円）→ 優先配送が自動で消える
□ ナノガラス1個＋ガラスクリーナー1個（7,960円）→ 優先配送が0円で入る
□ 2個のとき、まとめ買い割引（10%オフ）が消えていない
□ 支払い画面まで進み、優先配送が0円のまま残っている
□ 商品ページの「今すぐ購入」系ボタンから2個で進んだ場合も、優先配送が入るか
　（10/3-10/8は8,000円以上53件のうち特典が入ったのは18件。カートを通らない経路で入っていない可能性があるので、ここを必ず確認）

────────────────────────────────
終わったら

・うまくいかない画面があればスクショを送ってください
