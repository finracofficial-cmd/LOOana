2. ★仮説が外れた。何が違うのか
----------------------------------------------------------------

  8/21に「場所＋人ならまとめ買いが入る／用途だと入らない」と書いた。
  ムダ毛シェーバーは場所＋人なのに1.00なので、**この仮説は不十分。**

  差として実際に見つかったのは2つ。どちらも決定的だとは言えない。


  ■ 差1: 2つ目の理由を、本文が打ち消している

    まとめ買い枠  「🧳 自宅用と旅行用に分けて → 3個で15%OFF」
    本文（FAQ）  「長さ15.5cm・重さわずか113g。リップやコスメ感覚で
                  **ポーチに収まる**超コンパクト設計。一般的なスマホの半分以下の
                  軽さで、**旅行や出張にもそのまま持ち出せます**」

    → 「そのまま持ち出せる」＝1台で自宅も旅行もいける、と本文が言っている。
      2台目を買う理由が消える。

    ⚠️ ナノガラスの修正案（8/21）で私は「自宅用と持ち歩き用に2つ」を
      **推奨した**。矛盾しているように見えるので差を書いておく:

        ナノガラス本文 「化粧ポーチに**常備**しても負担ゼロ」
                       → 常備＝置きっぱなし。自宅に無い状態になる → 2個目が要る
        ムダ毛本文     「旅行や出張にも**そのまま持ち出せます**」
                       → 必要なときだけ携行。普段は自宅にある → 1台で足りる

      **正直に言うと、この差は細い。** ナノガラスの修正案の②は
      「常備」の一語に寄りかかっている。7日後の判定で点数/注文が動かなければ、
      この読み自体を捨てる。


  ■ 差2: 価格帯（こちらの方が効いている可能性が高い）

    2個買ったときの支払額（10%OFF後）

      足臭ブラシ      3,980 × 2 × 0.9 = **7,164円**
      インソール      3,980 × 2 × 0.9 = **7,164円**
      ナノガラス      3,980 × 2 × 0.9 = **7,164円**
      ムダ毛シェーバー 6,980 × 2 × 0.9 = **12,564円**  ← 1.75倍

    自店の実測CVR（価格帯の崖）
      3,980円 4.06% ／ 4,980円 3.81% ／ 5,980-6,980円 **2.70%** ／ 8,980円 0.53%

    1個で6,980円＝すでに崖の下にいる商品を、12,564円で2個買わせようとしている。
    **足臭ブラシを2個買う金額（7,164円）が、ムダ毛シェーバー1個より安い。**

    → 価格帯とコピーのどちらが効いているかは、このデータでは分離できない。
      ナノガラス（3,980円・コピーだけが違う）の7日後判定が、その分離になる。


  ■ 犯人ではなかったもの: 「一生モノ」「買い替え不要」

    最初これを疑ったが、**足臭ブラシもインソールも同じことを言っている。**

      足臭ブラシ 「消臭スプレーの買い足しも…もう一生不要です」

      インソール 「すぐヘタる安物インソールの買い替えも、もう不要です」 → 1.43
      ムダ毛     「替刃の買い足しも、高いサロン通いも、もう必要ありません」 → 1.00

    **「一生モノ」は点数/注文を殺していない。消す提案はしない。**
    打ち消しているのは「1台で複数の場面をカバーできる」と言う文の方。

4. 期待値（推計）— 優先度が低い理由
----------------------------------------------------------------

  ★以下の「+個」と粗利増は **推計**。改善幅を仮定して置いた値であり実測ではない。

    ムダ毛シェーバー 売価6,980 / 原価2,798 / 原価率40.1%
    2個目は10%OFFがかかるので、2個目の粗利 = 6,282 − 2,798 = **3,484円**

    点数/注文 1.00 → 1.10  → 週 +4.3個 → **週 +14,981円**（推計）
    点数/注文 1.00 → 1.20  → 週 +8.6個 → **週 +32,369円**（推計・aov試算と同値）

  比較（同じ推計方法）
    ナノガラス 1.06 → 1.20  → **週 +108,207円**  ← 3.3〜7.2倍

  さらに、ムダ毛シェーバーは商品そのものが弱い:
    倍率（粗利/注文 ÷ CPA(注文)）= **1.26 → 全負け圏**
    原価率 40.1%（自店で最悪の2商品のうち1つ）
    CTR×CVR **4.05‱** — 自店13商品で最下位（中央値9.88の41%）

  **結論: やる順番は ①ナノガラス → ②W固定 → ③UVハット → …… → ムダ毛。**
  ムダ毛シェーバーは点数/注文を直すより、商品として続けるかどうかの判断が先。

5. ついでに見つけたもの
----------------------------------------------------------------

  ■ 「バリエーションは売り切れているか販売できません」は売り切れの証拠ではない

    ムダ毛シェーバーのページで、ブラック・ブルー・ホワイトの3色すべてに
    この文字列が付いていた。一瞬「3色とも欠品」に見える。

    **違う。** これはテーマ（Dawn系）が**全商品・全バリアントに常時埋め込んでいる
    隠しラベル**で、CSSで隠され、実際に選べないときだけ表示される。

    実際に売れている商品でも同じだけ入っている（実測）:
      足臭ブラシ   5個  ／ インソール **11個** ／ ムダ毛シェーバー 3個

    **生HTMLにこの文字列があることを在庫切れの根拠にしない。**
    （WebFetchでの誤読を2回やっているので、ここに残す）


  ■ 要確認: 色違いで2個買ったとき、数量割引は効くのか

    ムダ毛シェーバーには**色が3つある**。
    まとめ買いの理由が「ご夫婦・ご家族で1台ずつ」なので、
    **買う側は色違いを選ぶ動機がある。**

    Shopifyの自動割引「Quantity break」が
      ・商品単位の合計数量で判定 → 色違いでも効く
      ・カート行（＝バリアント）単位で判定 → **色違いだと効かない**
    のどちらで設定されているかで、コピーの約束が守られるかが変わる。

    ページ側には割引アプリのマークアップが無く、サーバー側の自動割引なので
    **公開ページからは判定できない。管理画面で確認が必要。**

    もし後者なら、コピーを直すより先にこちらを直すべき。
    「家族で色違いを選んだら割引が消えた」はカート離脱の直接原因になる。

    ※ ただしインソール（バリアント11・点数/注文1.43）は成立しているので、
      これが主因だという証拠はない。**あくまで確認事項。**


  ■ 偽の緊急性が残っている（既知・削除ペンディング）

    「あと 15:00 で限定セール終了！⏰」（カウントダウン）
    「今 [ ] 人がカートに追加しています。」（人数はJSで後から挿入）
    「【本日終了⏰】」（商品タイトルに常設）
    「残りわずか お早めに」

    これは以前から挙げている削除対象。今回あらためて現存を確認した。
