Ⅰ. 日傘2本（長い＝完全遮光・UV日傘 / 短い＝形状記憶日傘）
============================================================

結論を先に:
「長いほうの効率が悪い」は、いまのデータでは成立しない。
悪いのは日傘というカテゴリそのもの。2本を1つの予算として絞るのが最適解。

根拠1 ─ 3窓で見ると勝ち負けが入れ替わる（広告費1円あたり利益）
  3日 8/13-15 : 長 +0.008 / 短 -0.016  → 短のほうが悪い
  5日 8/11-15 : 長 +0.213 / 短 +0.060  → 短のほうが悪い
  7日 8/09-15 : 長 +0.012 / 短 +0.068  → 長のほうが悪い
  → 宣言済みの統合判定「3窓すべてで低いほうを停止」は、いまの実測では成立しない。

根拠2 ─ CVRの差は誤差の範囲
  長 28件/1,481クリック = 1.89%
  短 66件/2,866クリック = 2.30%
  差 +0.41pt / 標準誤差 0.47pt / z = 0.89 → 有意差なし。
  この差を有意にするには長い方に約7,253クリック（広告費 約640,934円）が必要。
  2本合わせた7日利益が18,127円しかないので、優劣の検証コストのほうが桁で大きい。

根拠3 ─ 配信ファネルでは長いほうがむしろ強い
                    CPM     link_CTR   CPC(link)  Frequency  Reach
  長い            3,994円      4.52%      88.4円      1.161   28,231
  短い            3,248円      3.80%      85.4円      1.092   68,985
  CPMは長いほうが23%高いが、CTRが高いのでクリック単価はほぼ同じ（88.4 vs 85.4）。
  同一SKU・同一価格4,980円・同一原価1,309円の二重出品なので、
  この23%のCPM差は自社の2本が同じオークションで競っている分が入っている。

根拠4 ─ カテゴリごと沈んでいる（週次・合算）
                 7/19-25   7/26-8/01   8/02-08   8/09-15
  実売           2,080,893  1,722,333   996,996   540,081
  注文               371        303       182        94
  広告費           679,854    671,308   520,975   375,346
  MER               3.06       2.57      1.91      1.44
  前週比               —     -16.2%    -25.4%    -24.8%
  分岐MER 1.36 に対し、直近週は 1.44。余裕 +0.07。
  3週連続で −25%/週。この減衰が続けば来週は分岐割れ。

根拠5 ─ 2本合算での3窓判定は「−25%」で3窓とも一致
  余裕（MER−分岐）: 3日 -0.01 / 5日 +0.15 / 7日 +0.07  → 3窓すべて 0.30 未満
  頑健性（削減1円あたり利益 = 1 − 限界MER×粗利率、限界MER=平均×0.6/0.7/0.8）
    長い: +0.393 / +0.291 / +0.190  → 3端一致で「削ると増える」
    短い: +0.359 / +0.253 / +0.146  → 3端一致で「削ると増える」

→ 8/18 に実行すること（基準はここで宣言する。前倒しはしない）
  ① 統合判定（宣言済み）は「据え置き」で確定する見込み。どちらかを止める根拠はない。
  ② 代わりに「日傘2本を1つの予算とみなした3窓判定」を新たに適用する。
     8/17 終端の3窓すべてで合算の余裕 < 0.30 なら、2本とも −25%
     （形状記憶 35,000 → 26,250 ／ 完全遮光 15,750 → 11,800、合計 50,750 → 38,050）
  ③ 合算MERが分岐1.36を3窓すべてで割ったら、その時点で2本とも停止。
     いまの減衰率（−25%/週）が続くなら 8/22 前後に到達する。

→ 停止した場合に取り戻せる額（長いほうを止めた場合の試算・7日換算）
  長の注文が全部消える     週  -1,600円 / 月    -6,857円
  半分が短へ移る           週 +53,766円 / 月 +230,426円
  8割が短へ移る           週 +86,986円 / 月 +372,795円
  ※ 同一SKUなので移る可能性は高いが、実測していない。だから「止める」ではなく
    「2本まとめて絞る」を先に打つ。絞っても売上が落ちなければ共食いが実証される。
